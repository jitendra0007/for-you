# 💌 A Little Apology

An interactive, animated apology page — hearts, a typewriter message, a shy little "No" button that runs away, confetti, and a soft in-browser tune.

## Run it

Just open `index.html` in any browser. No build step, no dependencies.

Or deploy free on **GitHub Pages**: enable Pages on this repo (Settings → Pages → main branch, root), then visit
`https://<your-username>.github.io/<repo-name>/`.

## Customize

Everything is in three files:

- `index.html` — the words. Change the messages, cards, and promises to what you actually want to say.
- `style.css` — the vibes. The pink palette lives in the `:root` block at the top.
- `script.js` — the interactions. The typewriter lines are in `sorryLines`, and the "No" button's excuses are in `hints`.

Search for the placeholder `my love` in `index.html` and replace it with her name.

## Files
